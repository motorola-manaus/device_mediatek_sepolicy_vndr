# MediaTek Vendor SEPolicy (`device_mediatek_sepolicy_vndr`)

This repository contains the vendor SELinux policies for MediaTek platforms, tailored for Motorola MT6879 devices running Android 15/17.

## Directory Path in Source Tree

```bash
device/mediatek/sepolicy_vndr
```

## How to Clone

```bash
git clone https://github.com/motorola-manaus/device_mediatek_sepolicy_vndr.git -b seventeen device/mediatek/sepolicy_vndr
```
